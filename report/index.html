1. App Overview

Koshpal is a mobile-first financial management app that reads transactional SMS messages, organizes income and expenses into clear views, and helps users stay on top of budgets, reminders, and personal cash flow.

Target Users

Employees and individuals who receive bank or wallet SMS alerts and want a simple way to monitor their personal finances.

Core Purpose

Provide an automated, SMS-driven view of transactions, budgets, and reminders so that users can track spending, avoid missed payments, and make informed financial decisions.

3. Machine Learning & Intelligent SMS Processing

Koshpal includes an intelligent SMS processing module that uses machine learning to automatically decide which messages are relevant for financial tracking and how they should be interpreted as transactions.

Purpose

  • Reduce manual data entry by turning SMS messages into transactions.
  • Ignore non-financial messages to keep the app signal high and noise low.
  • Improve the quality and consistency of transaction data over time.

High-Level Flow

  1. An SMS is received on the user’s device (with appropriate permission granted).
  2. The message content is analyzed by the ML module to decide if it is financial.
  3. If relevant, the module detects key attributes such as credit or debit, amount, and balance cues.
  4. The structured result is handed to the transaction engine, which creates or updates a transaction record.

Benefits

  • Automation: Users do not need to type every transaction manually.
  • Accuracy: Consistent parsing reduces errors that can occur with manual entry.
  • Reduced Effort: Financial tracking becomes a by-product of normal phone use.

4. Overall System Flow (High Level)

At a high level, Koshpal connects SMS-driven data with budgets, reminders, and reports in a single, continuous flow:

  1. SMS Intake: The app reads relevant transactional SMS messages on the device.
  2. ML Filtering & Classification: The machine learning module filters non-financial messages and classifies valid ones.
  3. Transaction Creation: Financial messages are converted into structured transactions inside the app.
  4. Budgets & Insights: Transactions feed into budget views, overviews, and spending insights.
  5. Reminders & Follow-Up: Users set reminders that relate to upcoming payments or collections.
  6. Reports & Export: Key data is available for statements and internal reporting.

6. Next Planning (Domain-Specific)

The following improvements are planned for future development:

1. Machine Learning (ML) Model Improvement

The current ML model supports limited banks and message formats. Accuracy is acceptable but not optimal. Planned work includes:

  • Training the model with a significantly larger and more diverse dataset
  • Supporting more banks and SMS formats
  • Improving overall detection accuracy and consistency

2. Context-Aware Auto Categorization

Current auto-categorization works for most transactions but lacks deep contextual understanding. Planned improvements include:

  • Better context awareness based on transaction patterns
  • Improved category alignment
  • Reduced need for manual correction by users
